# 工作车整理免审启用与既有待审修正

仅发布免审功能代码不会改变员工当前绑定工作包的人工审核规则。V117 增加独立的、按门店和工作包条目限定的启用记录，避免为启用免审而发布尚未确认的班次、早餐时间等草稿。

用户已确认已有待审的工作车整理一并按免审修正。启用事务保存授权依据、原工作预期和原始提交快照，不修改提交、照片、真实审批意见、工作日期或已发布工作包。原始状态仍可为 `SUBMITTED`，工作台按有效审核规则显示完成并计入原工作归属日。已审核的历史记录不纳入待审修正。

异常工作、被驳回后的整改继续人工审核；主管抽查不合格撤回该工作的一次完成，整改人工复验通过后恢复。物品领用、耗用、遗留物接收和下达任务保持人工审核。新发布工作包条目拥有新的标识，沿用该版本自身的审核配置。

部署同一提交的 CI 成品并通过配对备份恢复、迁移、健康检查后，使用 `tools/operations/activate-cart-exempt-review.sql`，明确传入租户和两家授权正式门店标识。脚本以单事务生成启用和修正记录，可重复执行。应用账号对两张审计表只有读取权限，表强制租户隔离，禁止修改和删除。

验收应核对有效审核模式、待审队列、完成率投影、原始记录未变及修正快照数量，不能把数据库原始 `SUBMITTED` 状态当作仍需人工审核的唯一判断。
