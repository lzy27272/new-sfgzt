# F16 租赁、预付与待摊受控计划

API 前缀 `/api/v1/finance/accrual`，所有金额为精确十进制字符串。新计划不能绕过原合同/预付审批，也不能自动付款、退款、过账。

|接口|真实行为|
|---|---|
|GET context|授权账套和真实调度启用状态|
|GET/POST policies|创建与账套绑定的 PREPAID / LEASE_ACCRUAL 政策草稿|
|POST policies/{id}/publish|后台实际配置财务总监独立发布，不允许制订人自审|
|GET/POST plans|真实已批准 CONTRACT/PREPAYMENT 或 ACTIVE PREPAID 期初来源建立计划|
|GET plans/{id}|来源快照、已生成月份、实际可用依据、未摊余额、真实退款待办提示|
|POST plans/{id}/revisions|未来月份调整或提前终止，旧版本及旧月不可回写|
|POST revisions/{id}/review|配置财务总监独立确认当前版本；来源漂移必须重核|
|POST plans/{id}/run|逐月生成待复核、多部门精确分配凭证及同一来源事件|
|POST plans/{id}/finalize-termination|生效日达到且前序月份完整过账后释放未用预算承诺，不伪造退款|
|GET calendar|真实计划/月份错误与重试状态|

## 业务边界

- 原预付款使用实际付款减实际退款与已过账确认依据的较大值，并受原批准金额限制。没有资金/已核算余额时不产生本月假完成。
- 租赁权责计提根据已批准合同金额和受益期，贷方为真实负债科目；合同计提不要求先有现金，但不将计提当付款。
- 使用旧 `fo_action.AMORTIZE`、`fa_recurring_run` 的累计金额控制，仍有效的旧周期计划禁止建立第二轨。
- ACTIVE PREPAID 迁移期初显式关联 `fm_subledger`；只恢复经核对的剩余金额和受益期，不再生成购置确认、资金事实或期初重复凭证。
- 月金额向下取分，最后一月补尾；部门分配按累计比例取分，合计严格守恒。
- V104 计划的每个实际受益部门须明确 `financialCategoryCode`，来源于该店独立发布的费用类别，不由会计科目猜测。真实 `far_run` 才形成本期费用预算实际，不把预付资金、迁移余额或整笔合同批准当作本期费用。原合同有对应 COMMITTED 费用占用时按真实本月分配转出相应金额，`runId` 和不可变事件防重复释放；旧原政策月份/快照保留，余额不足明确列待核对。
- 本月之前待复核/未过账/已红冲的凭证须先处理，不允许跳月。部分资金不足保留真实待办，不把它改成零金额。
- 审核中的调整/终止会挡住其生效月份；未来终止不提前清除生效日前的应摊月份。
- 已终止余额仅显示“待真实退款/结算”，不代表退钱成功。原资金入口由统一资金控制域限制进一步付款。

## 自动执行

默认 `app.finance-accrual.scheduler-enabled=false`。上线启用须显式配置该项为 true，并提供 `app.finance-accrual.tenant-ids` 租户白名单。空白名单启动即拒绝。

调度以计划原制订人的真实有效账号/任职执行；失效不会造通配权限身份。每轮查找真正遗漏的月份，前序凭证未过账即保留错误并重试。只生成 DRAFT，独立复核/过账仍由财务进行。成功月份及失败尝试均可追溯。

## 验证

V107 每个实际受益部门份额可显式选择 `projectKind,projectId`；只能关联权限内、同组织同法人的真实已批合同或在建卡。同一部门允许分配到两个不同真实项目，权重与分币尾差仍总额守恒。独立批准版本保存项目来源快照，月度执行使用原冻结项目，不因后续在建转固而擅改历史项目；合同费用预算承诺仅对匹配类别、部门及项目的真实当期份额转出，运行重放不重复释放。

计划深链仅有 `planId` 时先读服务端真实计划，再使用该计划的 `bookId` 打开；不默认使用第一账套而隐藏原详情。

V111 月度生成在同一事务先保存实际 `far_run.allocations`，再从该真实来源冻结部门及项目辅助维度，精确拆分双方分录；来源事件直接复用凭证实际使用的同一快照，不再二次读取或覆盖。旧迁移版本没有辅助核算时仍保留原有精确分配路径，不重复分摊。

`FinanceAccrualIntegrationTest` 使用 Embedded PostgreSQL、迁移到 V111、`hotel_ai_os_app` 非超级用户和强制 RLS，共 14 项。覆盖政策/计划独立审核、实际资金不足、合同计提、冻结修订、终止退款边界、PREPAID 期初承接、金额尾差、同月并发幂等、组织/租户负面权限、锁期、真实项目份额双边辅助核算及调度失败保留。是否通过须以根代理统一 Maven 报告为准，本文不将源码存在当作验收通过。
