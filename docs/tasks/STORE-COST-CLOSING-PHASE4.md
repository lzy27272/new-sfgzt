# 库存成本闭环：第四阶段——成本分析与月结

## 交付范围

本地开发版本，接续规格换算、日清耗用审核和布草洗涤台账。入口为「门店库存与固定资产 → 成本分析与月结」。本轮没有合并、GitHub推送或云端部署。

已提供按门店、月、日期、物品及分类查询的真实成本汇总，单据来源明细、不可覆盖的历史月结快照、跨月补录/冲销和操作审计。它不是全店财务总账：人工、租金、能源、折旧、税费、发票/付款、PMS单房成本尚不在本阶段。

## 成本口径

| 业务 | 成本处理 |
| --- | --- |
| 采购、期初入库、普通库存退回 | 更新库存价值，不直接计入使用成本 |
| 审核通过的耗品、清洁用品耗用 | 按库存已过账的加权平均金额计费，不重新乘当前参考单价 |
| 布草日常使用登记 | 只记周转使用，不再次扣总库存、不重复计洗涤费用 |
| 合格回收布草 | 按送洗时冻结单价 × 合格数量记洗涤费；返洗和未回收不预估费用 |
| 确认报损 | 原库存加权平均损失，单列“报损损失”，不计入洗涤费 |
| 手工布草耗减、经营物品消耗 | 依据实际扣库流水单列，不能用来代替日常布草周转登记 |
| 盘点调整 | 独立展示；盘亏为正、盘盈为负，不混入使用及洗涤成本 |
| 已审核耗用/洗涤回收冲销 | 新增负向成本，恢复原金额，保留原单据、原业务日期和被冲回记录 |

“计入成本合计” = 使用及洗涤净额 + 报损净额；不含盘点调整。不同物品/单位的数量不相加。库存领用不是重复记一遍耗用。

金额和数量保留4位小数；数据库使用NUMERIC，传给前端时使用精确十进制字符串。页面不经浮点数转算大额金额，也不根据最新配置重算历史费用。

## 月结流程

1. 选择门店和月份。系统按租户时区确定当月，只能预览当月及以前月份。
2. 查看分类、每日和物品汇总；点击分类或日期筛选明细。明细保留业务日期、入账日期、操作人、来源和冲销关系，系统编号折叠在“查看来源与追溯编号”中。
3. 处理该月待审核耗用：全部批准或退回后才可月结。不能把未审核的耗用直接当作零成本。
4. 核对零金额记录、在洗布草及历史分类提示。零金额可能是明确免费，也可能是原始成本未录入，系统不虚构单价；月结人必须核实并在说明中记录情况。
5. 上月或更早月份才显示确认关账表单。填写说明并勾选核对确认；系统再次验证预览是否已变化。新记账或待核对事项变化会返回冲突，要求刷新核对。
6. 关账后保留汇总、分类、每日、物品和核对提示快照，记录操作账号、时间及说明。历史月结可分页调取。

在洗提示是“核对时仍未完成、送洗日期早于所选月末”的单数，不是重建的月末实物库存，不能把它当成应付发票或预估洗涤费。

## 历史与跨月更正

- 正向业务在原业务月份未关账时，按业务日期入账。
- 业务月份已关账的补录转入当前月份，保留原业务日期，标记跨月调整。
- 冲销统一按实际冲销日期入账；原业务日期和原费用事实不修改。即使原月份未关账，冲销也不倒改原业务日期。
- 本阶段不提供重开、直接改写、删除月结接口。更正必须走原业务流程的退回/冲销和正确重录，或有依据的库存调整，不能手改汇总数字。
- 原洗涤页面显示的是“当前有效回收费用”，历史已关账月份显示“当时确认费用”；跨月冲销时两者不同是预期行为。
- V66按租户回填原库存/洗涤事实，不改库存余额、不重估金额。没有历史分类快照的手工库存记录使用上线时物品名称/分类并明确提示核对；原始单位优先使用已存快照。既有未来日期的手工历史保留原日期和历史分类提示，不通过迁移伪造发生日期。
- 新成本事实、快照和审计不随5天图片清理删除；本阶段没有新增自动删除规则，支持至少3年对比分析的基础数据留存。

## 权限与并发

- 查看需要 `store-resource.read` 和门店组织范围；月结额外需要独立的 `store-resource.cost-close`。管理员可配置给适当岗位，普通库存编辑权限不能自动关账。
- 平台管理员沿用既有通配权限。新增权限未批量赋给普通岗位，不改变其默认授权。
- 两张新增表强制租户隔离；成本和月结数据由数据库触发器禁止更新/删除。
- 成本与原库存/回收/冲销同一事务写入；异常整单回滚，源事实唯一约束避免重复记成本。
- 记账取门店级共享事务锁，关账取相同键的独占锁；关账不反向锁定物品、订单或工作记录，不造成多物品操作锁升级。关账等待旧记账完成，后到的旧月业务等待关账提交后转入当前月。
- 预览采用一致性事务快照；关账在独占锁内重新计算预览指纹。相同月份、指纹和说明的重试返回同一结果，不能覆盖快照。
- React页面按账号、门店、月份隔离状态，防止旧月结响应覆盖新月份页面；使用服务端成功返回的快照更新界面。切换分类/日期复位分页，后台失败使用中文提示。

## 接口

前缀：`/api/v1/store-resources/hotels/{hotelId}/costs`

- `GET ?month=YYYY-MM`：本月默认；未关账预览 / 已关账快照。
- `GET /entries?month=YYYY-MM&page=0&kind=ALL&day=YYYY-MM-DD`：每页50条；日期可省略，必须在所选月内。
- `GET /closed-months?page=0`：每页12个月结。
- `POST /close`：month、previewToken、note、acknowledgeWarnings=true。

契约已追加到 `docs/openapi.yaml`。
