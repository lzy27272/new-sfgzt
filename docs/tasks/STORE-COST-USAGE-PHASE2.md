# 库存成本第二阶段：日清实际耗用审核联动

状态（2026-09-20）：本地开发和自动验证完成，已扩展客房日报、主管更正及经营成本汇总；真实浏览器验收待补，未合并、推送或部署。洗涤、月结和PMS来源规则分别见第三至第五阶段说明。

## 管理员启用

1. 门店库存与固定资产 → 物品配置：核对耗品、清洁用品、布草的基础单位、耗用单位、换算比例及期初库存。
2. 组织与权限：为拟任审核人员配置工作复核、门店库存查看和库存模块权限，按现有草稿/发布流程生效；本功能不会自动扩大岗位权限。
3. 门店库存与固定资产 → 日清耗用审核：选本店有效任职作为审核人并保存。可以是店长、店助、客房主管等符合权限的人员，不写死岗位。
4. 在测试门店安排实际耗用工作，由员工提交、指定审核人复核，再核对库存流水、数量、金额和日报。

未配置审核人的门店继续原有文字填报，不自动扣库。启用不回填旧记录、不补扣旧库存。首次启用后，旧草稿需按清单重新核对才能提交。暂不提供关闭开关，避免未审核记录失去归属。

## 业务流程与口径

- 自动接入客房服务员 `HKA_USAGE_RETURN`、`HKA_DAILY_REPORT`，以及夜班服务员 `NSA_DAILY_HANDOVER`；自定义工作项可由接口设置 `submissionPolicy.inventoryUsage=true`。本期未新增工作包编辑器的该开关。
- 员工选择本店启用物品，只填实际使用数量，选择后台配置的基础/耗用单位；显示换算后的基础数量。不向普通员工返回库存金额、采购成本或库存余额。
- 无耗用需明确勾选；保存草稿不记账，正式提交冻结品名、分类、单位、比例和数量快照。
- 提交后生成站内待审核通知。工作记录复核与耗用审核是同一动作，不需要审核两遍，不自动打开企业微信推送开关。
- 耗品、清洁用品：审核通过后生成消耗流水，按库存加权平均成本核算。布草：记录周转使用量，不减少布草总库存，不计算洗涤费或重复计采购成本。
- 任一物品库存不足：整个审核回滚，其他物品不部分扣减、工作不错误变为审核通过。补齐账面库存后可重新审核。
- 更换审核人后，待审核记录跟随新配置；旧审核人不得继续操作，保留最初分配快照与配置审计。
- 重复点击/网络重试、并发审核不会重复扣库。同一日清工作不能换记录编号重复入账。
- 员工可先在“客房服务员日报上传”工作项填写数量，也可先完成“耗品布草使用登记”。同一员工、门店、营业日的另一项工作须显式关联已有有效耗用；页面展示已关联数量，不重复发送一份数量。两边独立重复填写会被服务端拒绝。多个候选时提示人工核对，不自动选取一条。
- 早间领用、日报中心的纯文字字段和自动汇总不作为另一笔实际消耗，防止重复计费；不从任意文字猜测库存操作。本期不建立员工个人领用余额/余料退回台账。

## 退回、冲销与证据

- 审核退回不扣库存，员工更正后提交新版本，原记录保留。
- 已审核的记录由有库存记账权限的人填写原因后冲销：新增相反流水，恢复原数量与原成本，不按当前采购价重算。
- 数量填错时，门店指定审核人或管理员可对已审核记录使用“更正数量并同步库存成本”，填写原因；本人不得审核或更正自己的耗用。更正表单按基础单位带入旧数量，并校验当前配置版本。
- 更正保留原始提交和版本历史，先恢复上一版扣减数量及原金额，再按新数量和当前库存加权均价记账；所有物品一次成功或全部回滚。相同重试不会重复记账，过期版本拒绝覆盖。更正为无耗用也保留版本，允许后续再更正。
- 冲销用于撤销实际耗用，不删除工作完成事实、不覆盖原审核和流水；有更正版本时撤销最新有效数量。若只是改数量应直接使用更正功能，不先整笔冲销。
- 审核列表展示各自记录快照，证据链接使用具体记录编号，避免打开成后续更正版本。
- 日报草稿汇总中文品名、数量、更正原因及审核/冲销状态，已关联的另一项工作也同步更新；工作详情明确区分最新核定数量与原始证据。不展示内部编号或原始JSON。已提交日报保持原快照，后续变动通过耗用/库存历史追溯，不静默改写已提交报告。
- 审核页每种状态显示最近 100 条；账本记录不删除。大规模历史分页检索未在本期增加。

## 接口与数据库

- 新增 V64：配置、耗用主表、不可变明细，强制租户行隔离及跨表租户/门店外键；V63为前置单位换算迁移。
- V67追加更正主表、不可变更正明细、日报关联与当前有效明细视图。视图显式按租户过滤；更正通过独立来源编号产生新流水，不改写V64原明细。
- `/store-resources/usage-catalog?orgUnitId=...&businessDate=...&itemCode=...`：员工物品清单及可关联的当日耗用。
- `/store-resources/hotels/{hotelId}/usage-review-config`：查看/保存审核配置。
- `/store-resources/hotels/{hotelId}/usage-reviewers`：可选审核任职。
- `/store-resources/hotels/{hotelId}/work-usage`：待审核与历史。
- 原工作记录审核接口：原子执行复核、库存和日报草稿更新。
- `/store-resources/hotels/{hotelId}/work-usage/{recordId}/reverse`：冲销。
- `/store-resources/hotels/{hotelId}/work-usage/{recordId}/correct`：带期望更正版本与原因的数量更正。
- 统一物品锁定顺序，沿用库存余额锁；冻结提交时换算规则，即使之后修改比例也不改变旧申请数量。

## 经营中心口径与剩余启用条件

- 经营中心提供昨日总成本、昨日单房开房成本、截至昨日当月累计成本、截至昨日当月单房开房成本，以及日、月、自定义期间。昨天按门店时区的日历日计算；未完成PMS日结时单位成本保持不可计算，不把“昨天”悄悄改为前天。
- 经营金额按原营业日更新，仅包含已入账耗品、清洁用品和验收合格洗涤费；不含工资、房租、能耗等未接入费用。布草采购价不是洗涤单价，采购入库金额不是当期耗用成本。
- 月单房成本为期间成本合计除以同期全部用房间次合计，不平均每日比率；同房一天使用两次计2次。零间次、来源缺失、待审核或成本异常时提示原因，不伪造可核算值。
- 已关账财务月结保持原快照；跨月更正的财务记账按既有规则进入当前开放期间，经营分析仍归属原工作营业日。两种口径在页面明确区分。
