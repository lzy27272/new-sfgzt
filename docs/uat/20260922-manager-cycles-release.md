# 店长周期工作与员工周评发布说明

范围：已确认的周期工作方案和效果图；不新增一级菜单，不改写历史任务或月度KPI。

## 功能与规则

- 店长工作台增加周清8项、月清9项、季清6项；现有日清、团队工作入口保留。
- 工作归属周期独立于截止日期；跨月提交仍归原周期，首次启用前已过期事项不补造逾期。
- 下月工作与资源计划、空气能净水设备检查：当月28日18:00截止；安全专项检查保持20日。
- 净水设备不正常或药剂不足时必须填写处理安排，照片选填；不默认正常。
- 周评按本店员工选择，每人每店每周一份；人工0—100分、关注重点选填、未评不计零分。
- 保存草稿、保存并评估下一人、汇总提交、退回修改、再提交、复核通过形成闭环。
- 提交后锁定评分，原提交快照不随后续修改改变；保留历史评分及审核事实至少3年。
- 店长执行、负责该门店的副总复核；禁止自审、越店评估和越店复核。
- 新权限 manager-cycle.review 仅用于店长周期工作，不等同通用工作复核权；原岗位权限和数据范围不扩大。
- 对已有团队查看权的集团副总集团岗位方案复制发布新版本，原权限版本及管理员草稿保留；门店覆盖方案仍由管理员配置。
- 周/月/季报为已录入周期工作与证据索引的汇总视图，不额外增加任务；不声称自动导入PMS财务分析或AI代替人工评分。
- 客房服务员日报增加选填“计划卫生内容”“计划卫生房间号”；不恢复已取消的通用异常、工作结果题。
- 既有照片5天留存策略、PMS/OTA及KPI留存规则不变；本次不清理数据。

## 验收证据

- 前端328项自动测试通过；发布构建通过。
- 本地真实组件、隔离模拟接口：1536×1024桌面和390×844手机验证周期切换、状态筛选、汇总报告、评分为空校验、保存下一人、提交后只读；无横向溢出及页面错误。
- 后端隔离PostgreSQL回归覆盖周期生成幂等、跨期截止、分数范围与并发版本、提交快照、禁止自审、指定副总退回与通过、跨门店拒绝、现有日清和客房日报流程。
- 浏览器插件运行组件缺失，使用用户已批准的本地Playwright替代。截图与测试过程存放工作区外层 `.uat/20260922-manager-cycles/`，不将模拟业务数据发布云端。
- 设计对照：保留个人/团队双入口、四周期页签、四状态卡片、突出员工周评、桌面双栏和手机员工切换/底部操作栏；适配既有生产导航，未将效果图演示数字作为真实统计。
