## 发布交接与剩余边界

当前代码仍在本地修复分支。实际发布须同时发布前后端并执行新 V86；只更新网页不会补全旧物品。发布核对发现主线已使用 V83—V85，本次原 V83 已顺延为 V86，保留原有升级文件不变，并从 V85 重新验证。

部署前备份数据库并记录业务数据指纹。V86 有意允许变化的范围仅：LEGACY 物品/资产的 usage_scope_mode、row_version、updated_at，缺少的使用部门映射，以及追加的审计；不能把此例外扩大到库存数量、成本、岗位映射或历史记录。不得修改既有 V1—V85。

升级会提升旧配置版本：已填草稿数量保留，但遇到版本冲突需移除对应项后重新核对填写，不能绕过服务端版本校验。
