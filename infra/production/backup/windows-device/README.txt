四方馆中台备用设备连接登记包 V1
适用：Windows 11、NTFS 本机磁盘。默认保存位置：E:\中台备份。

这是第一步“连接登记”，不是已经开通的自动备份服务。

一、你需要做什么
1. 把整个 ZIP 文件复制到准备存储备份的另一台电脑。
2. 右键 ZIP，选择“全部解压缩”。不要在压缩包预览里直接运行。
3. 双击解压文件夹中的 01-Prepare-Backup.cmd。
4. 核对窗口显示的电脑系统、E 盘目录及剩余空间。
5. 确认是在备用电脑后，输入大写 YES，再按回车。
6. 看到成功提示后，只把 E:\中台备份\连接登记.json 发回当前对话。

若出现系统安全提示，请先确认文件来自本次对话并查看脚本。
不要关闭杀毒软件、不要关闭系统安全保护；组织策略阻止运行时请联系管理员。
启动器只为本次 PowerShell 进程设置脚本执行选项，不修改全局执行策略。
正常不需要“以管理员身份运行”。缺少 OpenSSH 客户端时，窗口会提示安装路径，
需由该设备管理员在系统“可选功能”安装；不安装 OpenSSH 服务器、不开放入站端口。

二、会改动什么
只在指定专用目录创建登记标记、identity 密钥子目录、连接登记.json。
identity 子目录限制为当前账号、系统和本机管理员访问，不改变 E 盘其他目录权限。
为后续无人值守，设备密钥不设置交互口令；本机管理员仍可读取，请保管好设备。
重复运行会校验并复用原身份；已有其他文件的目录、损坏或不匹配的密钥会拒绝覆盖。
不修改电源、睡眠、休眠、BIOS、开机设置、防火墙或计划任务。
不扫描个人文件，不连接云端，不上传文件，不格式化、不删除现有数据。

三、哪些内容可以发送
只发送“连接登记.json”：包含随机设备编号、公钥及指纹、系统版本、磁盘类型与容量、
拟用备份目录。不包含私钥、密码、数据库数据、个人文件或现有登录凭证。
不要发送 identity 文件夹，不要发送 device_ed25519，不要打包整个 E:\中台备份。
设备连接密钥与“数据库备份解密密钥”不是同一个东西，后者稍后还需独立安全保管。

四、收到登记之后
运维核对公钥后，才会配置云端只能下载指定备份的专用账号。
随后提供固定服务器指纹的连接配置，安装自动下载/校验/重试任务，并测试：
首份下载、重复运行不重复覆盖、断网重试、锁屏/重启后运行、版本保留及实际恢复。
服务器现有异地备份机制还需适配拉取确认，不能把只生成本机备份当成异地备份成功。
此包没有包含生产密钥或管理员登录信息，也没有解除现有部署备份门禁。

五、存储范围
数据库及 PMS/OTA 等数值汇总分别纳入清单，不能只备份数据库而遗漏独立文件。
业务历史保留三年与备份版本保留策略需要分别验收；图片五天规则不能误删长期汇总。
存储容量以实际增长监控为准。磁盘剩余空间充足不等于硬盘健康或已有备份可恢复。
