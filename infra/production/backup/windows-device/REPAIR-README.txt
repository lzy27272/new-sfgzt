四方馆中台：备用电脑自动备份修复包

操作：
1. 把整个 ZIP 发送到备用电脑，先全部解压。
2. 右键 03-Repair-BackupPull.cmd，选择“以管理员身份运行”。
3. 按系统提示允许运行，保持开机联网，不要关闭窗口。
4. 完成后把同一文件夹里的 repair-result.json 发回当前对话。
   如果连接失败，结果文件会附带本轮连接错误；详细日志也保存在 E:\中台备份\logs\connection-error-last.log。

修复范围：
仅针对登记的 E:\中台备份 和已登记的云服务器。先检查设备/服务器公钥指纹及原计划。
只调整现有连接私钥的文件归属和访问权限，使 SYSTEM 后台任务可以通过 OpenSSH 校验。
私钥内容不会更换、复制或发送，数据库解密密钥也不会放入本机。
更新两份同步程序文件以完整记录连接错误，并记录每次运行编号和实际运行身份。
原程序和权限配置留在 control\repair-编号 目录，可供受控回退；不要自行恢复旧权限。

验证：
使用一个临时、无定时触发器的 SYSTEM 任务实际下载并校验清单中的全部文件。
完成后删除该临时任务；如三分钟内尚未结束，会显示 PENDING 并让同步继续，不假报成功。
原来的每日04:30及开机备份计划不改动。此次验证不清理历史备份版本。
正常的每日同步仍保留原有历史版本管理规则。
新版以 control\accepted-bundle.json 原子保存完整清单和匹配回执；旧清单/回执文件只供兼容。
恢复时保留完整 data 目录和该权威文件；包缺失或权威文件损坏不能用旧兼容文件绕过校验。

不会重装系统、格式化磁盘、开放入站端口、修改账号密码或改变云端服务。
不要发送 identity 文件夹、device_ed25519、整个备份目录或数据库备份文件。
